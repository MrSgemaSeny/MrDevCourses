# Учебный план курса по вайбкодингу
_Mr Developer — Программа обучения_

---

## Уровни сложности

| Уровень | Описание | Недели |
|---------|----------|--------|
| **Уровень 1** | Инструменты, промпты, лендинги | 1–2 |
| **Уровень 2** | Архитектура, full-stack, один стек от и до | 3–4 |
| **Уровень 3** | ИИ, RAG, OAuth, транзакционная почта | 5 |

---

## Неделя 1 — Введение и инструментарий
> _Уровень 1_

- **Урок 1** — Вайбкодинг как методология: сравнение с классической разработкой, место AI-ассистентов в современном IT-рынке
- **Урок 2** — Настройка рабочего окружения: VS Code, Cursor, Antigravity, Claude, ChatGPT, Gemini — установка и верификация
- **Урок 3** — Git и GitHub с нуля: инициализация репозитория, первый коммит, GitHub Pages — деплой статики
- **Урок 4** — Структура проекта и MVP-мышление: файловая архитектура, README, agents.md
- **Урок 5** — Бизнес-идея: Customer Problem Statement, целевая аудитория, feature scope
- **Урок 6** — Лендинг бизнес-идеи: вёрстка через AI-ассистента, публикация на GitHub Pages

---

## Неделя 2 — Frontend-разработка (Маркетплейс)
> _Уровень 1_

- **Урок 1** — Feature-Sliced Design: слои, сегменты, публичное API модуля — планировка маркетплейса
- **Урок 2** — Старт проекта: роутинг, страницы, базовая бизнес-логика
- **Урок 3** — Углубление логики: ролевая модель (покупатель / продавец), условный рендеринг по роли
- **Урок 4** — Деплой на GitHub Pages: конфигурация base path, сборка и публикация
- **Урок 5** — Code review через Claude: рефакторинг, исправление архитектурных нарушений, финальный дизайн-аудит
- **Урок 6** — Финал маркетплейса: приёмочное тестирование, ретроспектива

---

## Неделя 3 — Full-Stack + 3D (Трекер денег)
> _Уровень 2_

- **Урок 1** — Системная архитектура: монолит vs микросервисы, выбор стека, ERD базы данных — планировка трекера
- **Урок 2** — Инициализация full-stack: настройка фронтенда, бэкенда и БД, связка окружений
- **Урок 3** — Закладка архитектуры: RBAC, JWT-аутентификация, защищённые роуты, миграции схемы
- **Урок 4** — OAuth 2.0 через Google: интеграция провайдера, мультиаккаунтность, проверка ролей в админ-панели
- **Урок 5** — Three.js: 3D-сцена, анимации, интерактив — Second Brain разработчика: Notion/Obsidian система
- **Урок 6** — Code review: масштабируемость архитектуры, рефакторинг, финальный деплой Render + Vercel

---

## Неделя 4 — CRM: Kanban + Trackers
> _Уровень 2_

- **Урок 1** — Полное планирование продукта: user stories, архитектурное решение, выбор стека с обоснованием
- **Урок 2** — Технический foundation: README по стандарту, углублённый Second Brain, финализация tech stack
- **Урок 3** — Самостоятельная работа студента: декомпозиция на фазы, написание промптов, старт реализации
- **Урок 4** — Telegram Bot: webhook-интеграция, алерты, уведомления о событиях CRM
- **Урок 5** — Code review + CI/CD pipeline: GitHub Actions, деплой на Vercel (фронт) и Render (бэк)
- **Урок 6** — Production-режим: smoke testing, мониторинг, работа с живыми данными

---

## Неделя 5 — Pensee (всё в одном)
> _Уровень 2 → 3_

- **Урок 1** — Архитектура финального продукта: scope, интеграционная карта всех компонентов — старт
- **Урок 2** — Подключение LLM API: Claude / OpenAI, prompt engineering, обработка ошибок и стоимость токенов
- **Урок 3** — AI-ассистент: chat-интерфейс, контекстное окно, streaming-ответы
- **Урок 4** — RAG-система и AI Core: Groq API, реактивный WebClient, Server-Sent Events (SSE), детерминированное закрытие подписок, PII-маскирование персональных данных
- **Урок 5** — Google SMTP / Gmail API: отправка транзакционных писем из приложения — подготовка к релизу
- **Урок 6** — Финал Pensee: полный деплой, нагрузочное тестирование, презентация продукта
