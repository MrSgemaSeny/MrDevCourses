# MrDevCourses — Архитектура навигации (Top-Nav & Quick-Nav Drawer)

## Суть задачи
Студент находится в уроке. Ему нужно проверить связанный контент (глоссарий, прогресс, дорожную карту) без потери текущего контекста и без перезагрузки видеоплеера.

Реализованная схема навигации (ADR-013):
1. **Top Navigation Bar** — единый верхний Header со сквозными ссылками на Каталог, Моё обучение, Профиль.
2. **Contextual Block** — внутри урока, карточка связанного термина с мгновенным открытием.
3. **Quick-Nav Drawer** — выдвижной ящик справа (Глоссарий, Прогресс, Roadmap) с сохранением состояния страницы.

## Движок 1 — Persistent Sidebar

**Что это:** фиксированная панель слева, видна на всех залогиненных страницах.
Лендинг — без сайдбара.

**Структура:**

```
[avatar + имя]
─────────────
Dashboard
Мои курсы
  └ Вайбкодинг (текущий)
     └ День 1 ✓
     └ День 2 ← активный
     └ День 3 🔒
─────────────
Глоссарий
─────────────
[streak badge: 🔥3]
```

**Техническое решение:**

```
src/
  app/
    layout/
      AuthenticatedLayout.tsx   ← новый файл
      Sidebar.tsx               ← новый файл
```

`AuthenticatedLayout` оборачивает все залогиненные роуты вместо текущего `App`.
Лендинг и `/auth/*` остаются в `App` без сайдбара.

Роутер меняется так:

```tsx
// router/index.tsx — схема изменений
{
  path: '/',
  element: <App />,           // без сайдбара
  children: [landing, auth]
},
{
  path: '/',
  element: <AuthenticatedLayout />,  // с сайдбаром
  children: [courses, lessons, dashboard, admin]
}
```

**Состояние sidebar'а** (свёрнут/развёрнут) — `useState` в `AuthenticatedLayout`,
передаётся через context. Не нужен Zustand/Redux — это UI-состояние одного layout'а.

## Движок 2 — Contextual Block

**Что это:** блок внутри урока, появляется при наличии связанных терминов/материалов.
Кнопка открывает глоссарий через Quick-nav Panel (не уход со страницы).

**Сценарий:** студент видит в тексте урока "GitHub client" →
в конце урока появляется блок:

```
┌─────────────────────────────────────────────────────┐
│ Термины из этого урока                              │
│                                                     │
│  Git  •  GitHub  •  Fork  •  Pull Request           │
│                                                     │
│  [Открыть глоссарий]                                │
└─────────────────────────────────────────────────────┘
```

**Техническое решение:**

На бэкенде в `Lesson` добавляется поле `glossaryTerms: String[]` (или парсинг
markdown-тегов `[!TERM]` которые уже есть в MarkdownViewer).
На фронтенде — компонент `LessonContextPanel.tsx` в `widgets/lesson/`.

При клике на "Открыть глоссарий" — открывает Quick-nav Panel с предфильтром
по этим терминам. Студент видит определение, закрывает панель, остаётся в уроке.

**Важно:** видео НЕ перезапускается, потому что Quick-nav Panel — overlay,
а не навигация. `<iframe>` остаётся в DOM.

## Движок 3 — Quick-nav Panel

**Что это:** правая панель-слайд (slide-in drawer), открывается поверх контента.
Не меняет URL. Не размонтирует текущую страницу.

**Три режима панели:**

```
[GLOSSARY]        [PROGRESS]        [ROADMAP]
──────────        ──────────        ─────────
Поиск термина     Курс: 40%         День 1 ✓
                  Streak: 3 дня     День 2 ← ты здесь
Git               След. урок:       День 3 🔒
  определение     завтра в 14:23    День 4 🔒
                                    День 5 🔒
GitHub
  определение
```

**Техническое решение:**

```
src/
  shared/
    ui/
      QuickNavPanel.tsx        ← новый файл
      QuickNavPanel.types.ts
  widgets/
    quick-nav/
      GlossaryView.tsx
      ProgressView.tsx
      RoadmapView.tsx
```

Состояние панели — context на уровне `AuthenticatedLayout`:

```tsx
interface QuickNavState {
  isOpen: boolean;
  mode: 'glossary' | 'progress' | 'roadmap';
  initialFilter?: string;   // для предфильтра из Contextual Block
}
```

**Открывается из:**
- Contextual Block кнопкой → mode: 'glossary', initialFilter: 'github'
- Sidebar иконка → mode: 'progress' или 'roadmap'
- Горячая клавиша (future consideration)

## Глоссарий — отдельная страница и/или панель

Глоссарий существует в двух формах:

1. `/glossary` — полная страница (доступна из sidebar'а)
2. `GlossaryView` внутри Quick-nav Panel — быстрый поиск без ухода

Данные одинаковые. Источник — либо отдельный `glossary` модуль на бэкенде
(рекомендую: `GET /api/v1/glossary`), либо статический JSON на фронте
(для MVP достаточно, курс один).

Для MVP: статический `glossary.json` в `src/shared/data/glossary.json`.
Добавить бэкенд-модуль когда контент начнёт меняться часто или нужна будет
admin-панель для редактирования терминов.

## Сохранение контекста при навигации

**Проблема:** YouTube iframe перезапускается при unmount компонента.

**Решение:** не размонтировать `LessonPage` при открытии Quick-nav Panel.
Панель — overlay (`position: fixed`), не замена роута.

Для перехода между уроками (prev/next) — перезапуск неизбежен, это ожидаемо.

**React Query** уже кешируют данные урока — при возврате из глоссария
данные не перезагружаются (staleTime нужно выставить явно, сейчас не задан).

Добавить в `lessonApi`:
```ts
queryKey: ['lesson', cId, lId],
staleTime: 5 * 60 * 1000,   // 5 минут — урок не меняется во время сессии
```

## Что НЕ делать

- Не тянуть Zustand/Redux для этой задачи — React context достаточно,
  состояние локальное для layout'а
- Не делать отдельный роут `/lesson/:id/glossary` — это убьёт видео
- Не хранить `isOpen` панели в URL-параметрах (query string) —
  лишняя сложность без benefit'а на текущем масштабе
- Не делать анимации через CSS transitions на `display: none/block` —
  использовать `transform: translateX` (GPU-ускорение, не вызывает reflow)
