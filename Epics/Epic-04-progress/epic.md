# Epic-04: Прогресс и профиль студента (Progress & Student Profile)

## Статус
- **Статус:** Completed
- **Приоритет:** P1

## Цель
Реализовать сводку прогресса для студента: текущий день обучения, процент прохождения, время обучения, количество завершенных проектов и профиль пользователя (`/profile`).

## Задачи
- [x] DTO и сервис расчета сводного прогресса `ProgressService` и `UserProfileService`.
- [x] Эндпоинты `GET /api/v1/progress`, `GET /api/v1/progress/{courseId}` и `GET/PUT /api/v1/users/profile`.
- [x] Telegram Bot привязка (`/start LINK_...` и по Email) с получением уведомлений.
- [x] Frontend: Страница курсов, профиль студента (`/profile`), расчетное время обучения, сделанные проекты и переключение целей.
