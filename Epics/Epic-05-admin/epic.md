# Epic-05: Панель администратора (Admin Dashboard & Management)

## Статус
- **Статус:** Completed
- **Приоритет:** P1

## Цель
Реализовать функции управления контентом, проверки домашних заданий, аналитики и триажа студентов для роли `ADMIN`.

## Задачи
- [x] Контроллеры и сервисы создания/редактирования курсов, модулей и уроков (`AdminCurriculumController`).
- [x] Очередь проверки домашних заданий (`/admin/homeworks`) с 1-click аппрувом и отправкой вердиктов.
- [x] Просмотр списка студентов (`/admin/students`), переключение ролей, ручное зачисление на курс и просмотр текущего урока.
- [x] Страницы системной телеметрии (`/admin/system`), логов безопасности (`/admin/audit`) и аналитики воронок (`/admin/analytics`).
- [x] Frontend: Изолированный `AdminLayout` со своим сайдбаром без наложения на публичный Header.
