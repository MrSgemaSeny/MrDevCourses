# Epic-05: Панель администратора (Admin Dashboard & Management)

## Статус
- **Статус:** Planned
- **Приоритет:** P1

## Цель
Реализовать функции управления контентом и студентами для роли `ADMIN`.

## Задачи
- [ ] Контроллеры и сервисы создания/редактирования курсов и уроков.
- [ ] Просмотр списка студентов и их прогресса по курсам.
- [ ] Ручная запись студента на курс администратором.
- [ ] Frontend: Админ-панель (`/admin`), таблицы курсов, формы добавления уроков.
