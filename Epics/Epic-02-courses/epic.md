# Epic-02: Каталог курсов и запись (Courses & Enrollments)

## Статус
- **Статус:** Completed
- **Приоритет:** P0

## Цель
Реализовать публичный просмотр доступных курсов и механизм записи студента на курс с фиксацией даты `enrolled_at`.

## Задачи
- [x] Сущности `Course` и `Enrollment`, репозитории и сервисы.
- [x] Эндпоинты `GET /api/v1/courses`, `GET /api/v1/courses/{slug}`.
- [x] Эндпоинт записи `POST /api/v1/courses/{courseId}/enroll`.
- [x] Идемпотентность записи (защита от повторной перезаписи).
- [x] Frontend: Каталог курсов, карточка курса с hover видео-превью, лендинг программы и запись.
