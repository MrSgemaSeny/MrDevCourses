# СТРАТЕГИЧЕСКИЙ РОАДМАП И ПЛАН РАЗВИТИЯ MRDEVCOURSES (LEVEL 3 EDUCATIONAL MVP)

> **Статус документа:** Генеральный план развития платформы и учебных курсов  
> **Контекст:** LMS-платформа Mr Developer для обучения full-stack инженеров и вайбкодеров  
> **Ограничение масштаба:** Строго Level 3 (Educational MVP / Локальная эталонная база). Проект не является Enterprise и никогда не выходит в релиз как Enterprise.  
> **Дизайн-система:** Строго Black & White Only (#0a0a0c, #141418, #18181b, text-white/zinc), Zero Emojis.

## 1. Архитектурный фундамент и философия платформы

MrDevCourses строится вокруг пяти незыблемых инженерных принципов:

1. **Zero Friction Setup через веб-карточку урока**:
   Студент никогда не ищет ссылки, файлы или системные промпты в Discord. Вся необходимая информация (исходный код, пошаговые чеклисты, видео, типичные грабли и ссылки на инструменты) встроена прямо в рабочую среду урока.
2. **Data-First RAG Pipeline (Сбор реальных затыков)**:
   Кнопка «Не получается / Сложно справляться» на каждом шаге урока не просто отправляет алерт ментору, а сохраняет в таблицу `student_help_requests` точный контекст: ID урока, номер шага чеклиста, код студента и ответ ментора. Это живой обучающий датасет для будущего автономного AI-тьютора на базе pgvector.
3. **Telegram Dashboard ментора**:
   Управление потоком студентов происходит прямо из смартфона ментора через Telegram Bot API: проверка ДЗ в 1 клик (`/approve`, `/reject`), мониторинг очереди (`/hw`), алерты о застрявших студентах (`/stuck`) и общая статистика (`/status`).
4. **Drip-Content на чистом SQL (Без cron-джобов)**:
   Открытие контента рассчитывается детерминированно в момент запроса студента:
   `is_unlocked = (NOW() - enrolled_at) >= ((day_number - 1) * INTERVAL '1 day') OR is_early_unlocked`.
   Никаких фоновых планировщиков, мгновенная точность и поддержка досрочного открытия ментором при одобрении ДЗ.
5. **GitHub-Grade Monochrome UX**:
   Интерфейс спроектирован для инженеров: глубокий темный фон, четкая 4-уровневая типографика, отсутствие отвлекающих стриков и геймификационного мусора, фокус на реальном написании кода.

## 2. Структура учебной программы (Curriculum Architecture: 3 уровня)

Учебный процесс разбит на 3 последовательных уровня сложности, охватывающих 5 недель интенсивной практики (30 уроков):

```text
+----------------------------------------------------------------------------------------------------+
|                                    ЛИНЕЙКА КУРСОВ MR DEVELOPER                                     |
+----------------------------------------------------------------------------------------------------+
| УРОВЕНЬ 1 (БАЗОВЫЙ): Вайбкодинг, Инструменты, FSD & Frontend           | Срок: Недели 1-2 (12 уроков) |
| - Инструментарий (Cursor, Antigravity, Claude, Git/GitHub)             | Проекты:                      |
| - Feature-Sliced Design (FSD), React 19, Tailwind v4                   | 1. Лендинг стартапа (GH Pages)|
| - Ролевая модель покупатель/продавец, деплой на GitHub Pages           | 2. Клиентский Маркетплейс     |
+------------------------------------------------------------------------+---------------------------+
| УРОВЕНЬ 2 (ОСНОВНОЙ ФЛАГМАН): Промышленная Full-Stack Архитектура      | Срок: Недели 3-4 (12 уроков) |
| - Модульный монолит Spring Boot 3.3, Java 17, PostgreSQL 17            | Проекты:                      |
| - Stateless JWT в httpOnly cookie, JTI Blacklist, Google OAuth2        | 1. 3D Трекер денег (Three.js) |
| - Three.js 3D-сцена, Second Brain инженера                             | 2. CRM Kanban + Telegram Bot  |
| - CRM Kanban, Telegram Webhooks, CI/CD Pipeline (Vercel + Render)      |    + CI/CD Pipeline           |
+------------------------------------------------------------------------+---------------------------+
| УРОВЕНЬ 3 (ПРОДВИНУТЫЙ): Мультимодальный AI SaaS & RAG Core            | Срок: Неделя 5 (6 уроков)    |
| - Архитектура AI Core, LLM Streaming через Server-Sent Events (SSE)    | Проект:                       |
| - Векторная RAG-система на PostgreSQL pgvector, реактивный WebClient    | Финальный продукт Pensee      |
| - PII-маскирование персональных данных, Google SMTP транзакции         | (Полноценный AI SaaS)         |
+------------------------------------------------------------------------+---------------------------+
```

### Подробная сетка уроков по модулям

#### Модуль 1: Неделя 1 — Введение и инструментарий (Уровень 1)
* **Урок 1**: Вайбкодинг как методология: сравнение с классической разработкой, место AI-ассистентов в современном IT.
* **Урок 2**: Настройка рабочего окружения: VS Code, Cursor, Antigravity, Claude, ChatGPT, Gemini — пошаговая верификация.
* **Урок 3**: Git и GitHub с нуля: инициализация репозитория, первый коммит, GitHub Pages — деплой статики.
* **Урок 4**: Структура проекта и MVP-мышление: файловая архитектура, README по стандарту, `AGENTS.md`.
* **Урок 5**: Бизнес-идея: Customer Problem Statement, целевая аудитория, feature scope и декомпозиция.
* **Урок 6**: Лендинг бизнес-идеи: верстка через AI-ассистента, адаптивность, публикация на GitHub Pages.

#### Модуль 2: Неделя 2 — Frontend-разработка: Маркетплейс (Уровень 1)
* **Урок 7**: Feature-Sliced Design (FSD): слои (app, pages, widgets, features, entities, shared), планировка архитектуры.
* **Урок 8**: Старт проекта: роутинг (React Router v7), страницы каталога, карточки товаров, базовый стейт.
* **Урок 9**: Углубление логики: ролевая модель (покупатель / продавец), условный рендеринг и права доступа.
* **Урок 10**: Деплой на GitHub Pages: настройка dynamic base path, SPA 404-fallback, сборка в GitHub Actions.
* **Урок 11**: Code review через Claude: рефакторинг, исправление архитектурных нарушений, дизайн-аудит (Deslop).
* **Урок 12**: Финал маркетплейса: приемочное тестирование, запуск боевого проекта, ретроспектива.

#### Модуль 3: Неделя 3 — Full-Stack + 3D: Трекер денег (Уровень 2)
* **Урок 13**: Системная архитектура: монолит vs микросервисы, выбор стека, ERD базы данных PostgreSQL.
* **Урок 14**: Инициализация full-stack: настройка Spring Boot 3 + React 19 + PostgreSQL, связка локальных окружений.
* **Урок 15**: Архитектурный фундамент: RBAC, Stateless JWT в httpOnly cookie, Flyway-миграции схемы данных.
* **Урок 16**: Google OAuth 2.0: Authorization Code Flow, нейтрализация захвата аккаунтов, ролевой шлюз.
* **Урок 17**: Three.js: интерактивная 3D-сцена финансов + Second Brain разработчика (Notion/Obsidian).
* **Урок 18**: Code review и деплой: аудит уязвимостей, оптимизация N+1 запросов, деплой на Render + Vercel.

#### Модуль 4: Неделя 4 — CRM: Kanban + Telegram Bot (Уровень 2)
* **Урок 19**: Полное планирование продукта: user stories, спецификация API contracts, выбор стека с обоснованием.
* **Урок 20**: Технический foundation: README по стандарту, углубленный Second Brain, настройка Docker/PostgreSQL.
* **Урок 21**: Самостоятельная работа студента: декомпозиция на спринты, написание промптов, старт реализации канбана.
* **Урок 22**: Telegram Bot: интеграция Telegram Bot API, вебхуки, алерты о перемещении лидов в CRM.
* **Урок 23**: Code review + CI/CD: GitHub Actions пайплайн, автоматические тесты, деплой на Vercel и Render.
* **Урок 24**: Production-режим: smoke testing, мониторинг через Actuator, работа с реальными данными.

#### Модуль 5: Неделя 5 — Мультимодальный AI SaaS Pensee (Уровень 3)
* **Урок 25**: Архитектура финального продукта: интеграционная карта компонентов, контракты взаимодействия.
* **Урок 26**: Подключение LLM API: Anthropic Claude / OpenAI / Groq, prompt engineering, обработка лимитов.
* **Урок 27**: AI-ассистент: чат-интерфейс, контекстное окно, Server-Sent Events (SSE) стриминг чанков.
* **Урок 28**: Векторная RAG-система: PostgreSQL pgvector, векторизация текста, PII-маскирование персональных данных.
* **Урок 29**: Google SMTP / Gmail API: отправка транзакционных писем, PDF-экспорт отчетов (Flying Saucer).
* **Урок 30**: Финал Pensee: полный деплой боевого сервиса, нагрузочное тестирование (Artillery), защита диплома.

## 6. Чеклист качества и инженерные стандарты (Quality Gates)

Каждое изменение в рамках роадмапа обязано соблюдать строгие метрики:
1. **Тестовое покрытие**:
   - Backend: 100% зелёные JUnit-тесты (текущий показатель: 250/250 passed).
   - Frontend: 100% зелёные Vitest-тесты (текущий показатель: 80/80 passed, 33 suites).
   - Сборка фронтенда: 0 ошибок компиляции (`tsc -b && vite build`).
2. **Workflow Second Brain**:
   - Тесты прошли -> Запись в журнал (`journal/YYYY-MM-DD/mrdevcourses.md`) -> Git commit/push.
3. **Безопасность**:
   - Полная изоляция через `SecurityUtils.getCurrentUserId()` (защита от IDOR).
   - Append-Only защита таблиц аудита на уровне триггеров PostgreSQL.
   - Отсутствие хардкода секретов в git-истории.
4. **Дизайн**:
   - Строго Black & White Only. Запрещены любые цветные плашки (зеленый, синий, янтарный).
   - Полный запрет на эмодзи в UI, коде, коммитах и документации.
