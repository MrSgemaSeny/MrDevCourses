# ADR-003: Stateless аутентификация через Google OAuth2 + JWT в httpOnly Cookies

## Статус
Accepted

## Дата
2026-08-31

## Контекст
Требовалось обеспечить безопасную сессию пользователя без сохранения состояния в памяти сервера (stateless), исключив риски XSS-атак (кража токенов из localStorage) и CSRF-уязвимостей.

## Решение
1. Хранить подписанный JWT-токен исключительно в защищённых cookies с атрибутами:
   - httpOnly = true (запрет доступа из JavaScript/DOM).
   - secure = true (передача только по HTTPS в production).
   - sameSite = Lax (защита от CSRF при межсайтовых переходах).
   - path = /
2. Авторизация через Google OAuth2 и fallback на Email/Password.
3. Дополнительная защита через Token Bucket Rate Limiting (Bucket4j + Caffeine) на эндпоинты авторизации и AI-тьютора.

## Последствия
- Полная защита токенов от компрометации через XSS.
- Сервер не хранит сессий в памяти, легко масштабируется горизонтально.
