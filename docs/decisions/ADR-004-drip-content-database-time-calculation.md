# ADR-004: Расчёт Drip-контента на уровне базы данных без фоновых планировщиков

## Статус
Accepted

## Дата
2026-08-31

## Контекст
Учебная программа MrDevCourses построена по принципу постепенного открытия уроков (drip content: 1 день = 1 урок от даты зачисления). 
Использование фоновых cron-задач для регулярной смены статусов уроков в базе данных создаёт проблемы рассинхронизации часовых поясов, лишнюю нагрузку на I/O и потенциальные сбои при остановке сервиса.

## Решение
Вычислять доступность урока строго на лету в момент запроса пользователя по формуле SQL/JPA:
(NOW() - enrolled_at) >= ((day_number - 1) * INTERVAL '1 day')
Все метки времени строго хранятся и обрабатываются в UTC (spring.jpa.properties.hibernate.jdbc.time_zone=UTC, TIMESTAMP WITH TIME ZONE).

## Последствия
- Нулевые накладные расходы на фоновые cron-демоны.
- Мгновенная точность расчёта доступа к контенту в реальном времени.
- Детерминированное тестирование логики доступа без необходимости манипулировать системными часами планировщиков.
